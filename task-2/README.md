# Автотесты виджета поддержки Учи.ру

Тестовое задание на стажировку QA Fullstack. За основу взял [исходный репозиторий](https://github.com/uchiru/aqa-intern-challenge), исправил два теста и добавил ещё один на закрытие и повторное открытие виджета.

Стек: TypeScript, Playwright, Chromium.

## Как запустить

Понадобятся Node.js 22.14 (версия указана в `.nvmrc`) и npm. Из корня репозитория:

```bash
cd task-2
npm ci
npx playwright install chromium
npx playwright test
```

Тесты работают с реальным сайтом `https://uchi.ru`, поэтому для запуска нужен доступ к сайту и сервису виджета.

Открыть HTML-отчёт из папки `task-2`:

```bash
npx playwright show-report
```

При падении сохраняются скриншот и trace. Их можно посмотреть в отчёте; сами файлы находятся в `test-results/`.

## Что исправил

- **Выбор главной страницы.** При повторных запусках сайт отдавал разные варианты главной. В группе `c` (`/index_v3`) встроенного виджета не было, и тест ждал кнопку до таймаута. Перед открытием страницы задаю cookie `ab_mainpage_redesign=a`, чтобы запускать сценарии на варианте с виджетом.
- **Селекторы кнопок.** Кнопку открытия нахожу по `data-test="openWidget"`, а кнопку «Написать нам» по `data-test="button_feedback_form"`. Убрал зависимость кнопки открытия от внешней обёртки. Старый селектор `[class^=btn]` не находил кнопку перехода к форме.
- **Ожидание статей.** Метод `.all()` возвращал пустой массив, если список ещё не загрузился. Теперь возвращаю `Locator` и нажимаю на первую статью через `.first().click()`. Playwright дожидается её появления и доступности.
- **Проверка заголовка.** Заменил чтение текста через `textContent()` на `await expect(locator).toHaveText(...)`, чтобы проверка дожидалась обновления интерфейса.
- **Баннер cookie.** Добавил `addLocatorHandler`: баннер закрывается при появлении перед действием или проверкой, а его отсутствие не задерживает тест. Служебная копия баннера исключена из селектора.

Локаторы и действия с виджетом оставил в [WidgetPage](tests/widget.page.ts). Сценарии и проверки находятся в [widget.spec.ts](tests/widget.spec.ts).

## Сценарии

1. **Открытие виджета.** Проверяются видимость и начальный заголовок «База знаний Учи.ру».
2. **Переход к форме поддержки.** Тест открывает первую популярную статью, нажимает «Написать нам» и проверяет заголовок «Связь с поддержкой».
3. **Закрытие и повторное открытие (дополнительный тест).** После закрытия виджет должен скрыться, а кнопка открытия должна остаться видимой и активной. После повторного открытия проверяются начальный заголовок и наличие популярной статьи.

Дополнительный сценарий выбрал, потому что первые два теста не проверяют, можно ли закрыть виджет и воспользоваться им снова.
